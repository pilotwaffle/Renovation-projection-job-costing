## 1. Competitor Overview

### Tier 1: Premium All-In-One Solutions ($300-500+/month)

#### **Buildertrend** (Market Leader)
- **Target:** Custom home builders, remodelers
- **Pricing:** $299-$499/month (Core to Pro plans)
- **Strengths:**
  - Comprehensive client communication features
  - QuickBooks integration
  - Mobile app with offline capabilities
  - Custom estimating templates
  - Daily logs and activity tracking
- **Weaknesses:**
  - No digital takeoff capabilities
  - Steep learning curve (non-intuitive UI per reviews)
  - Expensive for small contractors
  - Basic estimating features

#### **Procore** (Enterprise Leader)
- **Target:** Large commercial contractors
- **Pricing:** ~$375+/month (custom)
- **Strengths:**
  - Enterprise-grade job costing
  - Multi-tier approval workflows
  - Deep integrations with major systems
  - Change order management
  - AI-powered analytics
- **Weaknesses:**
  - Overkill for small contractors
  - Complex setup and training required
  - Very expensive

#### **CoConstruct** (Now merged with Buildertrend)
- **Target:** Custom home builders
- **Pricing:** $49-$299/month
- **Strengths:**
  - Highly customizable estimates
  - Client portal for approvals
  - Fixed pricing for unlimited users
  - QuickBooks sync
- **Weaknesses:**
  - Being phased out (merged with Buildertrend)
  - Limited to residential construction
  - Steep learning curve

### Tier 2: Mid-Range Solutions ($150-300/month)

#### **JobTread**
- **Target:** Pool builders, remodelers, general contractors
- **Pricing:** $159/month (annual) or $199/month (monthly) + $20/user
- **Strengths:**
  - All-in-one: estimating, budgeting, CRM
  - Scalable for growing businesses
  - No tiered features (all features included)
  - Good for specialty contractors
- **Weaknesses:**
  - Higher per-user costs add up
  - Limited mobile functionality details

#### **Knowify** (QuickBooks Top-Rated)
- **Target:** Small to mid-size trade contractors (10-200 employees)
- **Pricing:** Not publicly disclosed
- **Strengths:**
  - Template-based quoting
  - Real-time financial insights
  - Customer portal
  - Strong mobile app
  - QuickBooks integration
- **Weaknesses:**
  - Pricing not transparent
  - May be too feature-rich for micro contractors

#### **LiveCosts**
- **Target:** Small and medium contractors
- **Pricing:** Not publicly disclosed
- **Strengths:**
  - Real-time tracking: labor, materials, plant, subcontractors
  - Budget vs actuals at a glance
  - Mobile app for field updates
  - Strong variance analysis
- **Weaknesses:**
  - Limited information available
  - Unclear pricing model

### Tier 3: Budget-Friendly Solutions ($50-150/month)

## 3. Gap Analysis

### Critical Gaps (Competitive Disadvantage)

1. **No Budget Templates**
   - Competitors: 80% offer this
   - Impact: Users waste time recreating common scopes
   - User Story: "As a contractor, I remodel 50 kitchens/year with similar scope"

2. **No Dashboard/Analytics**
   - Competitors: 100% have visual dashboards
   - Impact: Users can't see portfolio-level insights
   - User Story: "I manage 5 jobs and need to see which are over budget at a glance"

3. **No Automated Alerts**
   - Competitors: 90% have variance alerts
   - Impact: Users must manually check for overruns
   - User Story: "I want an email when any job goes 10% over budget"

4. **No PDF Export**
   - Competitors: 95% have PDF generation
   - Impact: Can't share professional-looking budgets with clients
   - User Story: "I need to send a budget PDF to clients for approval"

5. **No CSV Import/Export**
   - Competitors: 85% have this
   - Impact: Manual data entry for bulk items
   - User Story: "I have 200 line items in Excel from my estimator"

### Important Gaps (Reducing Value)

6. **No Change Order Management**
   - Competitors: 70% offer this
   - Impact: Can't track scope changes systematically
   - User Story: "Client wants to upgrade flooring mid-project"

7. **No Client Portal**
   - Competitors: 40% offer this (premium feature)
   - Impact: Missing client-facing differentiation
   - User Story: "Clients constantly email asking for budget updates"

8. **No Document Management**
   - Competitors: 60% have this
   - Impact: Contracts/photos stored elsewhere
   - User Story: "I need to attach receipts to scope items"

9. **No Activity Feed**
   - Competitors: 30% have this
   - Impact: Hard to see recent changes across jobs
   - User Story: "What did my foreman update yesterday?"

10. **Limited Reporting**
    - Competitors: 100% have custom reports
    - Impact: Can't generate monthly summary for accountant
    - User Story: "I need a monthly cost report by category"

### Nice-to-Have Gaps (Differentiators)

11. **No Native Mobile App**
    - Competitors: 80% have native apps (iOS/Android)
    - Impact: PWA is acceptable but less polished
    - Note: PWA planned in roadmap

12. **No GPS Time Tracking**
    - Competitors: 30% have this (specialty feature)
    - Impact: Can't verify field team locations
    - User Story: "I want to see if crew actually on site"

13. **No Offline Mode**
    - Competitors: 20% have full offline (complex feature)
    - Impact: Field workers need internet access
    - User Story: "Basement renovations have no WiFi"

14. **No Team Messaging**
    - Competitors: 30% have built-in chat
    - Impact: Users rely on external tools (SMS, Slack)
    - User Story: "Foreman messages me on WhatsApp about issues"

15. **No Multi-company Support**
    - Competitors: 50% support this (enterprise)
    - Impact: Can't serve contractors with multiple LLCs
    - User Story: "I run 2 companies and need separate books"

#### **3. CSV Import/Export**
**Why:** 85% have this, essential for bulk data entry and reporting
**User Value:** Import 200 line items from Excel in 30 seconds
**Implementation:**

**Import Flow:**
1. Upload CSV file (drag-and-drop or file picker)
2. Column mapping UI:
   - CSV columns → Our fields (description, category, material cost, labor hours, labor rate)
   - Auto-detect common column names
3. Preview table (first 10 rows)
4. Validate data (required fields, numeric formats)
5. Import with progress bar
6. Show summary: "Imported 187 items, 13 errors"

**Export Flow:**
1. "Export to CSV" button on budget page
2. Download CSV with all scope items
3. Include columns: Category, Description, Est Material, Est Labor Hrs, Est Labor Rate, Est Total, Actual Material, Actual Labor Hrs, Actual Total, Variance

**Libraries:**
```bash
npm install papaparse @types/papaparse  # CSV parsing
```

**Server Action:**
```typescript
'use server'
export async function importScopeItemsAction(
  budgetVersionId: string,
  csvData: { description: string, category: string, ... }[]
) {
  // Validate + batch insert
  const supabase = createServerClient()
  const { data, error } = await supabase
    .from('scope_items')
    .insert(csvData.map(row => ({
      budget_version_id: budgetVersionId,
      description: row.description,
      // ... map fields
    })))

  return { imported: data?.length, errors: [] }
}
```

**Time Estimate:** 2-3 days
**Difficulty:** Medium

#### **5. Variance Alerts & Email Notifications**
**Why:** 90% have alerts, prevents costly overruns
**User Value:** Get email when any job exceeds 10% variance
**Implementation:**

**Phase 1: In-App Alerts (Week 1)**
- Badge on dashboard/job card if variance > threshold
- Alert banner on job detail page
- Store alert settings in user profile:
  ```typescript
  alert_threshold_percent: 10 // Default 10%
  ```

**Phase 2: Email Notifications (Week 2)**
```bash
npm install resend  # Email service ($0 for 100 emails/day)
```

**Server Action (runs on scope item update):**
```typescript
'use server'
export async function updateActualCostAction(itemId, actualCost, actualHours) {
  // Update item
  await supabase.from('scope_items').update({ actual_material_cost, actual_labor_hours }).eq('id', itemId)

  // Calculate new variance
  const variance = await calculateJobVariance(jobId)

  // Check threshold
  const user = await getJobOwner(jobId)
  if (variance.percentage > user.alert_threshold_percent) {
    await sendEmail({
      to: user.email,
      subject: `Budget Alert: ${job.name} is ${variance.percentage}% over budget`,
      html: `Your job "${job.name}" has exceeded the budget threshold...`
    })
  }
}
```

**Settings Page:**
- Allow user to configure:
  - Email notifications on/off
  - Variance threshold (default 10%)
  - Notification frequency (immediate, daily digest)

**Time Estimate:** 3-4 days
**Difficulty:** Medium

#### **11. Role-Based Access Control (RBAC)**
**Why:** 70% have this, needed for teams
**User Value:** Owner, PM, Foreman have different permissions
**Implementation:**

**Roles:**
- **Owner:** Full access (CRUD all jobs, manage team)
- **Project Manager:** CRUD assigned jobs, view others
- **Foreman:** Update actual costs on assigned jobs, view only
- **Client:** Read-only via client portal (from #10)

**New Tables:**
```sql
CREATE TABLE team_members (
  id UUID PRIMARY KEY,
  organization_id UUID REFERENCES organizations(id), // New concept
  user_id UUID REFERENCES auth.users(id),
  role TEXT CHECK (role IN ('owner', 'pm', 'foreman')),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE job_assignments (
  id UUID PRIMARY KEY,
  job_id UUID REFERENCES jobs(id) ON DELETE CASCADE,
  user_id UUID REFERENCES auth.users(id),
  role TEXT CHECK (role IN ('pm', 'foreman')),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**RLS Policy Updates:**
```sql
-- Users can see jobs they own OR are assigned to
CREATE POLICY "Users see assigned jobs" ON jobs
  FOR ALL USING (
    user_id = auth.uid() OR
```

```typescript
'use server'
export async function predictCostsAction(jobDescription: string, sqft: number, location: string) {
```
